# WhisBass（ウィスベース）

「口笛から、ベースフレーズへ。」

卒業研究「口笛を用いたベース演奏支援システムの開発」のためのPCブラウザ向けWebアプリです。作曲経験の少ない利用者が、口笛による直感的な入力からベースフレーズを生成・試聴できることを目的としています。

## 主な機能

- ブラウザのマイクを使った最大15秒の録音と自動停止
- 録音中の経過時間と波形表示
- Spotify Basic Pitchによる実音声からの音符抽出
- 24キー（メジャー12・マイナー12）の自動推定と手動変更
- 選択したキー内の最も近い音への補正
- 一般的な4弦ベース音域（E1〜G3）へのオクターブ移調
- 極端に短い音と小さいノイズ音の除外
- 検出音（灰色）と補正後の音（青色）の簡易ピアノロール表示
- テンポ50〜160 BPMでの試聴
- MIDIおよび合成ベース音WAVのブラウザ内生成・保存

## 利用条件とプライバシー

- PCブラウザ向けです。スマートフォンは研究対象外です。
- 単旋律を想定しています。静かな場所で、1音ずつはっきり口笛を吹いてください。
- 録音音声、検出音、補正結果はブラウザ内だけで処理します。外部サーバーへの送信・保存は行いません。
- 公開環境でマイクを使うにはHTTPSが必要です。`localhost` はブラウザにより安全な接続として扱われます。
- Basic Pitchの初回モデル読み込みには、端末性能によって数秒以上かかる場合があります。

## 開発環境

- Node.js 22以上
- pnpm
- Vite + TypeScript

```bash
pnpm install
pnpm dev
```

型検査と本番ビルド：

```bash
pnpm typecheck
pnpm build
```

生成物は `dist/` に出力されます。Viteの `base` はビルド時に相対パスへ設定しているため、GitHub Pagesのサブディレクトリ配信にも対応できます。

## Basic Pitchモデル

`public/model/` に次の2ファイルを同梱しています。公開時にも必須です。

- `model.json`
- `group1-shard1of1.bin`

参照先は `document.baseURI` を基準にしており、公開先のサブディレクトリが変わってもモデルを読み込めるようにしています。

## 実変換の診断

開発・公開後の動作確認では、URL末尾に `?diagnostic=1` を付けると、880Hzのテスト音をブラウザ内で生成してBasic Pitchへ渡します。画面に「診断完了」と検出したMIDI番号が表示されれば、同梱モデルによる推論が動作しています。この診断音も外部へ送信されません。

2026年8月4日の確認では、880Hzから1音（MIDI 81）を実際に検出しました。

## 音色について

現在のベース音は、実際の楽器サンプルではありません。Web Audio APIの三角波・正弦波・フィルター・音量変化を組み合わせた合成音です。したがって「自然なエレキベース音」は今後の改善項目です。ライセンスが明確な実サンプルを導入した場合は、この欄へ出典と利用条件を追記します。

## 研究上の位置付け

本システムは単なる「口笛からMIDIへの変換」ではありません。Basic Pitchで検出した音を、推定または利用者が指定したキーの音階へ補正し、4弦ベースに適した音域へ移調した上で、すぐに試聴・保存できる初心者向け演奏支援システムです。

評価では次の説明を使用します。

> 作曲経験の少ない利用者が、口笛による直感的な入力からベースフレーズを生成・試聴できるシステムを開発し、20名の利用者評価によって操作性および有用性を検証する。

## 既知の制約

- 短いフレーズではキー推定を誤る可能性があるため、利用者が変更できる設計です。
- 重なった音、伴奏、環境騒音が多い録音では精度が低下します。
- ブラウザやマイク機器によって録音形式・音量が異なります。
- WAVは合成音であり、実サンプル音源ではありません。
- AIモデルを含むため、JavaScriptの本番ファイルは約1 MBあります。初回表示後の変換待ち時間は端末性能に左右されます。
