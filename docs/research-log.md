# WhisBass 研究・開発記録

卒業研究で説明できるよう、実装の変更内容、変更理由、動作確認の結果を記録する。今後の修正でもこのファイルへ追記する。

## 2026年11月6日：ノイズ・重複音・音の分断への第一次改善

### 改善前に確認された問題

- 環境音など、口笛と関係のない音を多数検出する。
- 単旋律の入力でも二つの音を同時に検出する場合がある。
- 一つの音が複数の短い音符へ分断される。
- Basic Pitchの出力をほぼそのまま採用しており、誤検出を十分に除外できていない。

### 変更内容

- マイク入力の自動増幅上限を80倍から12倍へ抑え、小さな環境音の過剰な増幅を防いだ。
- 180Hz未満と5,000Hzより上の成分を弱める前処理を追加した。
- Basic Pitchの音符判定基準と最小音長を引き上げた。
- 入力音のピーク値とRMS（平均的な音量）の両方で無音を判定するようにした。
- 口笛として不自然な音域、短すぎる音、信頼度の低い音を除外した。
- 同時刻に重なった候補から、より強く長い一音を選ぶ単音化処理を追加した。
- 同音または半音差の音が0.14秒以内の隙間で分断された場合、一音へ結合する処理を追加した。
- ブラウザのノイズ抑制を有効にし、自動音量調整を無効にした。

### 利用者による確認結果

1. 無音に近い状態では音符を検出しなかった。多少の鼻息も誤検出しなかった。
2. 一音を長く吹いた場合は正しく検出した。ただし再生音が実際の入力より短く感じられた。
3. 短いフレーズは良好に変換できた。

ノイズ除去と単音化は改善した一方、全体的に再生音が短く感じられることが新しい調整課題となった。

## 2026年11月6日：再生音の持続時間の改善

### 原因

検出音符の長さだけでなく、合成ベース音の音量が発音直後から終了時刻まで減衰し続けていた。そのため、データ上は音符が続いていても、聴感上は早く消えたように感じられた。

### 変更内容

- 音符の長さを0.94倍に短縮していた処理を廃止した。
- 発音直後の減衰後、終了直前まで一定の音量を維持するサステイン区間を追加した。
- 最後の0.08秒で自然に音量を下げるようにした。

### 次回の確認項目

- 一音を長く吹いた場合、入力と同程度の長さに聞こえるか。
- 短いフレーズで音同士が不自然につながらないか。
- MIDI保存とWAV保存でも同じ長さが維持されるか。

## 2026年11月6日：再生音の持続感の第二次改善

### 利用者による追加確認

- 検出された音符の長さとピアノロールの線には大きな問題がなかった。
- しかし、再生音は線の長さまで十分に鳴っているように聞こえず、短音を短く鳴らしたような聴感だった。

この結果から、音符検出ではなく合成ベース音の音量包絡に原因が残っていると判断した。

### 変更内容

- 発音直後の減衰時間を0.12秒から0.08秒へ短縮した。
- 持続部分の音量を0.18から0.28へ上げ、線の終端直前まで明示的に維持した。
- 音の消え際を0.08秒から0.045秒へ短縮し、音符の大部分を持続区間として使うようにした。
- ローパスフィルターを1,200Hzから1,600Hzへ広げ、持続中の音を聴き取りやすくした。

### 次回の確認項目

- ピアノロールの線が表示されている間、ベース音も持続して聞こえるか。
- 音の終端が不自然に途切れたり、次の音と過度に重なったりしないか。
- 通常再生と保存したWAVの両方で同じ聴感になるか。

## 2026年11月6日：短音検出の復元と長さ比例型の再生

### 利用者による追加確認

- 短い口笛が検出されにくく、比較的長く音を出さなければ結果へ反映されなかった。
- 再生音の持続感にも明確な改善を感じられなかった。
- 期待する動作は、検出音が長いほどベース音も相対的に長く響くことである。

直近二回の変更は再生音のみで、検出処理は変更していなかった。短音が落ちる原因は、第一次ノイズ対策で引き上げた最小音長にあると判断した。

### 変更内容

- Basic Pitchが音符として採用する最小フレーム数を7から4へ戻した。
- 前処理後に採用する最小音長を0.11秒から0.07秒へ緩和した。
- ノイズ対策の音量基準、帯域制限、単音化、断片結合は維持した。
- 合成音の音量包絡を、固定秒数による処理から音符の長さ全体に比例する処理へ変更した。
- 音符の先頭約12%を立ち上がり、中央約82%を一定音量の持続、末尾約6%を消音として構成した。

### 次回の確認項目

- 短い口笛が再び結果へ反映されるか。
- 鼻息や環境音を除外する性能が維持されているか。
- ピアノロール上の長い音ほど、ベース音も相対的に長く響くか。
